⚠️ Network Error — "Failed to fetch"

Your browser blocked the request to Anthropic's API because this page is opened as a local file (file://). Fix it by serving the file over HTTP — takes 30 seconds:

Option 1 — VS Code (recommended) Install the Live Server extension → right-click index.html → Open with Live Server
Option 2 — Python (built into Mac & most PCs) python -m http.server 8080 Run in the Scooby folder, then open http://localhost:8080 in Chrome
Option 3 — Node / npx (if Node is installed) npx serve . Run in the Scooby folder, then open the URL it prints

🧩 Install Scooby on Chrome

Download the extension package, then follow these 4 steps to load it into Chrome.

⬇️ Download Scooby Extension (.zip)
  1. 1 Unzip the downloaded file — you'll get a folder called chrome-extension
  2. 2 Open Chrome and go to chrome://extensions
  3. 3 Enable Developer mode (toggle in the top-right corner)
  4. 4 Click Load unpacked and select the unzipped chrome-extension folder

After loading, click the 🧩 puzzle icon in Chrome's toolbar and pin Scooby for quick access.
